## 🚀 Getting Started

### Run Locally

1. Clone this repository:

   ```bash
   git clone PLACEHOLDER_GITHUB_REPOSITORY_URL
   ```

2. Open the project folder:

   ```bash
   cd portfolio-website
   ```

3. Open `index.html` in your browser, or use the Live Server extension in VS Code.

## 🌍 Deployment

This website can be hosted for free using **GitHub Pages**.

1. Push the project files to a GitHub repository.
2. Open the repository's **Settings**.
3. Select **Pages**.
4. Under the deployment settings, select the appropriate branch, usually `main`, and the root folder.
5. Save the settings and wait for deployment.
6. Copy your published website URL into the Live Demo section above.
